# hxyfront-62002 剧场灯光Cue表管理 · 可核对的排练台

源提示词编号：2

在灯位与 Cue 表管理基础上，为排练期的通道调整提供可核对、可仲裁、可升级的排练台。

## 排练台规则

1. **改动即作废**：排练中改动灯具通道值并保存后，引用它的下游 Cue 立即标记「已作废·待重算」；
   未逐条重新确认前，**当前场景预览保持已确认版本不变**（可切换「若确认后」预览重算结果）。
2. **保存分两种做法**：
   - **只改当前Cue**：只写入当前 Cue；若紧邻的下游引用是顺延格，自动在该处回填升级前旧值并锁定，
     之后每条 Cue 都不跟随变动。
   - **继续顺延**：当前 Cue 写入显式值并向下游带变，每遇到**显式锁定**格才停止传播。
3. **主控台 / 备份台同存仲裁**：同一盏灯的两次保存按到达时刻（毫秒）裁决，**先到一版生效**；
   晚到一版不覆盖数据，只在「同存仲裁台账」列出与先到版的逐条差异（亮度差、做法、时刻、席位），
   可核对后选择重提或维持。页面内置双台同存演练器（可调亮度/做法/到达偏移）。
4. **旧数据升级回填**：v1 数据只有显式值、没有锁定标记。侧栏可载入 v1 旧数据（表中显示 🔓），
   执行升级时**按当时的显式值回填锁定**（🔒），回填数量与逐条 Cue 分布写入审计日志。

## 数据语义

- 每个「Cue × 通道」格只有两种状态：`🔒 显式锁定值`（阻挡点）或 `⤵ 顺延`（沿用上游最近显式值）；
  点击格子可切换。
- Cue 表行内数字为按触发顺序解析后的实际亮度；舞台灯位图、场景预览均以解析结果渲染。

## 技术栈

React 19 + Vite 7 + TypeScript（纯函数引擎在 `src/model.ts`，行为可离线核验）

